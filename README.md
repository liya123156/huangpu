# 黄浦大区｜目标与活动量工作台

本仓库用于维护黄浦大区目标与活动量工作台的**程序代码**。当前仓库公开，**禁止提交真实人员名单、入职日期、活动量明细、业绩、顾客或房源资料、沟通记录、完整备份及任何密钥**。

## 页面

01 活动量看板 · 02 市场与市占 · 03 带看流向 · 04 重点组和人 · 05 跟进记录 · 06 数据导入。

保留深紫目录、可增删改和排序的表头、门店—店组—个人展开、绩效四象限、司龄分段以及复制表格为图片。

## 数据与程序分开

- 所有真实数据只在用户浏览器内导入和保存，不上传到 GitHub。
- 已整理的数据包通过 **06 数据导入 → 恢复完整备份**载入；兼容 V2.3 JSON 数据包。
- 替换程序不等于迁移浏览器数据。换域名、浏览器或设备前，先导出完整备份。
- 当前没有账号鉴权、云端同步、截图自动识别或联网 AI。勿将本地保存视为企业级权限或备份。
- 新页面默认不含真实数据。没有提供的业绩和目标保持空白，不填 0，不自动划分绩效高低。

## 统计口径

- 保留源表周期。月内累计与近30天快照分别展示，不将后者伪装成当月。
- 区、店、组、个人的总计不重复相加；比例不直接相加或平均。
- 人员以员工编码优先匹配。未具名明细保留待核，不擅自分配给个人。
- 四象限是沟通线索，不是奖惩或人员去留结论；必须先确认规则和数据。
- 司龄按所选截止日计算：未满6个月、满6未满12个月、满12未满24个月、满24个月及以上。

## 本地运行与发布

这是无构建依赖的静态网页。运行 `python3 -m http.server 8000` 后打开 `http://localhost:8000`。

可使用 Netlify 等静态站点服务连接本仓库，发布目录为仓库根目录，构建命令留空。也可以由仓库管理员自行开启 GitHub Pages。**代码提交不代表网站已经部署。**

建议使用新版 Chrome 或 Edge。Excel解析使用浏览器原生解压能力；图片剪贴板需要浏览器权限，失败时可下载 PNG。

## 开发边界

数据库、统一登录、云端附件、实时协同及 AI 应作为独立受控服务后续接入；不要把管理员密钥或模型密钥放在前端。请先使用脱敏数据验收任何新功能。
